# HR Models

Custom Frappe application providing Job Description and Performance Appraisal DocTypes.

## Installation

```bash
bench get-app hr_models https://example.com/hr_models.git
bench --site <site-name> install-app hr_models
```

## DocTypes
- Job Description
- Job Task (Child)
- Performance Appraisal
- Performance Objective (Child)
- Behavioral Competency (Child)
- Evaluation Approval (Child)
